# Fellahi 2.0 — Starter

## المحتويات
- `index.html`: واجهة عربية متجاوبة، تعمل محلياً دون خادم.
- `worker.js`: نقطة بداية Cloudflare Worker لتحليل صورة نبات عبر OpenAI Responses API.

## تشغيل الواجهة
افتح `index.html` في المتصفح أو ارفع محتويات المجلد إلى GitHub Pages.

## إعداد Worker
1. أنشئ Worker في Cloudflare.
2. ألصق محتوى `worker.js`.
3. أضف `OPENAI_API_KEY` في Worker Settings > Variables and Secrets كـ Secret.
4. انشر Worker واختبر المسار `POST /diagnose`.
5. اربط الواجهة بعنوان Worker بعد إضافة معالجة رفع الصورة وإرسالها.

مهم: ملف الواجهة الحالي لا يرسل الصور بعد؛ يعرض معاينة محلية فقط. لا تضع مفتاح API في HTML أو JavaScript. استخدام OpenAI API قد يترتب عليه تكلفة.

## ملاحظات زراعية
حاسبة التسميد تحفظ البيانات فقط ولا تخترع جرعات. حاسبة الماء تستخدم ET₀ وKc وكفاءة الري لتقدير أولي، ويجب إدخال قيم موثوقة وتعديلها وفق المطر ورطوبة التربة وجودة المياه.
بيانات السجلات محفوظة في `localStorage` على نفس المتصفح والجهاز، وليست قاعدة بيانات سحابية أو نسخة احتياطية.
